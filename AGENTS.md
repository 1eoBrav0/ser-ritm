# Ритм

Локальный Telegram Mini App: календарь, задачи, заметки и напоминания.

- Python 3.11+, стандартная библиотека, SQLite; интерфейс на HTML/CSS/JavaScript.
- Сохранять простой код. Комментарии нужны для нетривиальных причин и ограничений.
- Любой запрос к записям должен ограничиваться текущим пользователем.
- Не доверять initDataUnsafe. Проверять подпись и возраст Telegram initData на сервере.
- Не добавлять токены, базу данных и персональные записи в Git.
- Деморежим доступен только локально; не включать его для публичного URL.
- Проверки: python -m unittest discover -s tests -v.
- Интерфейс и документация на русском. Описывать только реализованные возможности.
