# Ритм — ежедневник в Telegram

Личный учебный проект: календарь, задачи и заметки, которые открываются прямо в Telegram. Хотелось собрать в одном месте расписание, повторяющиеся дела и напоминания, а затем довести приложение до запуска на сервере.

[Попробовать бота](https://t.me/serritmbot) · [Исходники](../README.md) · [Устройство приложения](architecture.md)

## Что попробовать

1. Отправить боту `/start` и открыть ежедневник. У нового пользователя нет готовых задач; функции показывает короткое обучение.
2. Добавить «Работа» на понедельник с 15:00 до 17:00, выбрать повторение по понедельникам и посмотреть загрузку недели. Отдельный день можно изменить без изменения всей серии.
3. Для проверки уведомления создать невыполненную задачу на несколько минут вперёд и выбрать «Напомнить → В момент начала». Сообщение приходит в личный чат бота.

## Как устроено

Python на сервере, HTML/CSS/JavaScript в интерфейсе. Локальная версия использует SQLite, опубликованная — PostgreSQL в Supabase. Приложение работает на Render, расписание напоминаний запускает cron-job.org. Локальный запуск доступен без токена Telegram.

| Что нужно было решить | Как это сделано | Где посмотреть |
| --- | --- | --- |
| Повторения с разовыми изменениями | Хранится правило серии, а изменения конкретных дат — отдельно. Время серии учитывает её часовой пояс. | [recurrence.py](../ritm/recurrence.py) |
| Личные записи разных пользователей | Сервер проверяет подпись Telegram, создаёт сессию и ограничивает запросы владельцем. | [auth.py](../ritm/auth.py), [store.py](../ritm/store.py) |
| Сохранение данных после перезапуска сервера | Для облака добавлен PostgreSQL; локальная SQLite осталась для простого запуска. Перенос выполняется одной транзакцией в пустую базу. | [postgres.py](../ritm/postgres.py), [перенос](../migrate_to_postgres.py) |
| Повторные запросы Telegram и одновременные проверки напоминаний | Состояние обработки и короткие блокировки хранятся в базе. | [hosting.py](../ritm/hosting.py) |

## Что проверено

В GitHub Actions запускаются Python-тесты, проверки JavaScript и отдельные проверки с PostgreSQL. Они охватывают доступ к чужим записям, подпись входа, повторения, напоминания и откат переноса при ошибке. [Тесты](../tests/) · [Результаты запусков](https://github.com/1eoBrav0/ser-ritm/actions).

Интерфейс проверен на ширине от 320 до 1440 px, отдельно — в низком окне и альбомной ориентации. После размещения вручную проверены открытие через Telegram, сохранение задачи после перезахода и реальное получение напоминания.

## Ограничения

Это первый проект для портфолио. Пока нет импорта через интерфейс, перетаскивания событий и связи с внешними календарями. Бесплатный сервер после простоя может открываться около минуты. Напоминания проверяются раз в минуту; при сбоях возможны задержки и повторная отправка.
