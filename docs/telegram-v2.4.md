# Telegram-подключение · v2.4 · 19 октября 2026

Подключён существующий бот @serritmbot. Токен хранится только в локальном .env, не включается в Git и архивы, не выводится в журнал. Проверены getMe и отсутствие существующего webhook.

После явного разрешения Серафима запущен временный Cloudflare HTTPS-туннель к отдельному порту 8766. Telegram-приложение использует отдельную базу data/telegram.sqlite3 с пустыми профилями. Основная база локального ежедневника остаётся data/ritm.sqlite3. Серверная проверка Telegram-подписи и разделение пользователей обязательны; публичный демовход запрещён.

Настроены имя и описание бота, команды start/app/help/stop/privacy и кнопка меню «Ежедневник». Получатель getUpdates обрабатывает только личные сообщения. Напоминания содержат кнопку открытия, /stop отключает их без удаления записей. В интерфейс добавлена поддержка системной кнопки Telegram «Назад».

Проверено:

- 39 автоматических тестов прошли. Новые проверки охватывают команды, отключение напоминаний, сохранность записей, кнопку в уведомлении, отказ от чужого webhook, безопасные сообщения об ошибке без токена, обязательную Telegram-подпись и разделение профилей в публичном режиме.
- JavaScript прошёл синтаксическую проверку.
- Официальный cloudflared 2026.10.1 загружен из cloudflare/cloudflared; SHA256 совпал с digest опубликованного GitHub-ассета.
- Публичный HTTPS-адрес отвечает, /api/entries и создание сессии без Telegram возвращают 401.
- Telegram API подтвердил команды и кнопку меню с временным адресом. Telegram может нормализовать URL, добавляя завершающий `/`.
- Серафим подтвердил открытие ежедневника внутри Telegram.

Настоящее уведомление по расписанию пользователя в этой проверке не создавалось. Отправка напоминаний проверена автоматическими тестами; реальная проверка — задача на несколько минут вперёд после /start.

Текущий временный адрес хранится в data/telegram-runtime.json и меняется после перезапуска. Для повторного запуска — start-telegram.cmd. Остановка процесса отключает временный доступ. Для постоянного сервиса нужен сервер с постоянным HTTPS-адресом.
