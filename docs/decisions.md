# Решения первой версии

## Python без зависимостей

Серафим знаком с основами Python, поэтому HTTP-маршруты, доступ к базе и обработка бота написаны на нём. Стандартная библиотека позволяет запустить проект без установки пакетов. Для публичного сервера разумно заменить HTTP-слой на поддерживаемый production-стек, сохранив модули данных и проверки авторизации.

## Обычный JavaScript

Интерфейсу из четырёх разделов пока не нужен фреймворк и отдельная сборка. Это уменьшает число инструментов, которые нужно освоить одновременно. Пользовательский текст экранируется перед вставкой в HTML.

## SQLite

Локальный файл подходит для первой версии и небольшого числа пользователей. Соединение открывается на операцию, транзакции короткие, включён WAL. Записи индексированы по владельцу и дате. Рост нагрузки потребует отдельной оценки и миграций схемы.

## Честный деморежим

Без Telegram создаётся случайный локальный профиль. Он не имитирует настоящую Telegram-авторизацию. Для публичного URL деморежим запрещён при старте; пустые данные входа не дают сессию. Новые профили не содержат примеров. Обучение использует отдельные иллюстрации и не создаёт записей. Известные неизменённые записи первой проверки архивируются один раз при обновлении старой базы.

## Напоминания

При подключении токена один поток получает `/start`, другой выбирает напоминания каждые 15 секунд. Неудачные отправки ждут две минуты. Завершённые дела не отправляются. В локальном профиле вместо внешних сообщений используются уведомления внутри открытой страницы.

## Объём первой версии

Календарь месяца, обзор выбранного дня, задачи, события, заметки и напоминания. Повторения и недельную сетку отложили: сначала нужно проверить основные сценарии на реальных делах.
