# Ритм v2.5 — минимализм и полный экран

19 октября 2026 года.

## Что изменилось

Интерфейс сохранил зелёный цвет и утверждённый логотип Ser. Фон стал спокойнее, заголовки крупнее. Боковое меню получило функциональные значки, календарь — более ясное выделение даты. Переключатели работают как единый сегментированный элемент. В форме записи меньше визуального шума, действия остаются внизу. Анимация короткая и отключается при системном предпочтении уменьшенного движения.

На компьютере приложение использует всю ширину окна, с ограничением ширины содержимого для читаемости. На телефоне остаётся нижняя навигация. Интерфейс учитывает безопасные отступы Telegram при полном экране.

## Полный экран

При запуске внутри Telegram на ПК приложение автоматически вызывает requestFullscreen, если клиент предоставляет API версии 8.0 или новее. Узкое стартовое окно Telegram Desktop тоже распознаётся как ПК. Выход пользователя не вызывает повторное принудительное включение. Вверху есть кнопка входа и выхода из полного экрана. В обычном браузере запрос выполняется только по нажатию пользователя, если разрешён браузером.

Версия Telegram и платформа могут не поддерживать полный экран даже при наличии метода. Ответ UNSUPPORTED обрабатывается без ошибки запуска, недоступная кнопка скрывается. При неудаче ручного запроса показывается объяснение. Приложение не может принудительно развернуть системное окно неподдерживаемого клиента; его можно развернуть средствами Telegram/Windows.

Официальное описание: https://core.telegram.org/bots/webapps — requestFullscreen, exitFullscreen, fullscreenChanged, fullscreenFailed и безопасные отступы.

## Проверка

- 39 тестов Python: доступ к данным, повторения, напоминания и обработчики Telegram.
- 9 проверок управления полным экраном, в том числе запуск в узком окне ПК, неподдерживаемый клиент, выход и отказ браузера.
- 16 проверок расчёта занятости из planner.test.cjs; синтаксис app.js проверен.
- Просмотр действующего интерфейса в браузере при ширине 1440 и 390 пикселей: расписание, календарь, фильтры и форма записи. На мобильном размере горизонтальной прокрутки нет. Временный размер окна сброшен.
- Реальное автоматическое разворачивание в Telegram Desktop ещё должен подтвердить пользователь: в этой среде управление нативным Telegram недоступно. Поведение Telegram API проверено с имитацией ответов клиента.
