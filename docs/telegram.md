# Telegram-версия Ser Ритм

Бот владельца проекта: [@serritmbot](https://t.me/serritmbot). Приложение открывается кнопкой в личном чате или кнопкой меню «Ежедневник». Main Mini App в профиле через BotFather — дополнительная настройка; для текущего способа запуска она не требуется.

## Запуск с компьютера

1. Сохрани токен BotFather в `BOT_TOKEN` файла `.env` рядом с `server.py`. Не публикуй файл и не присылай токен в чат. Если токен уже попал в переписку, перевыпусти его через BotFather (`/revoke`), замени значение и перезапусти Telegram-версию.
2. Нужен Python 3.11+. Для отдельной установки Windows Python выполни `python -m pip install -r requirements.txt`, чтобы были доступны часовые пояса IANA. В комплектном Python Codex они уже есть.
3. На компьютере владельца `cloudflared` уже лежит в `tools/cloudflared.exe`. В новой копии проекта запусти `python install_tunnel.py`: он скачает официальный Windows x64 клиент Cloudflare из GitHub и проверит опубликованный SHA256. Файл программы не входит в Git и архив исходников.
4. Запусти **start-telegram.cmd**. Или из терминала: `python run_telegram.py`.
5. Дождись строки «Готово» и открой бота → `/start` → «Открыть ежедневник».

Для обычной локальной версии остаётся `start.cmd` / `python server.py` и адрес 127.0.0.1:8765. Параметр `.env DEMO_MODE=1` сохраняет этот режим. Локальный сервер не запускает получение Telegram-сообщений.

Telegram-запуск сам использует отдельный порт 8766 и `demo=False`, вне зависимости от локального DEMO_MODE. Внешний доступ идёт только к этому порту. База Telegram — `data/telegram.sqlite3`, база браузерного ежедневника — `data/ritm.sqlite3`. Локальные записи не копируются в Telegram автоматически. Не запускай несколько получателей getUpdates для одного токена. `data/telegram.lock` препятствует повторному запуску этого проекта.

## Что настраивается автоматически

Проверяются токен и отсутствие чужого webhook, затем задаются имя «Ser Ритм», описание, список команд и кнопка меню с текущим HTTPS-адресом. Существующий webhook автоматически не удаляется.

- `/start` — приветствие, подключение личного чата для напоминаний, кнопка открытия.
- `/app` — актуальная кнопка открытия; не включает отключённые напоминания.
- `/help` — инструкция.
- `/stop` — отключает напоминания, сохраняя задачи и заметки. Повторное `/start` включает их.
- `/privacy` — информация о данных.

Сообщения из групп, от других ботов и сообщения с несовпадающим отправителем/личным чатом игнорируются. Входящие тексты не превращаются в задачи и не сохраняются как переписка: задачи создаются в Mini App.

## Напоминания

Отправь `/start`, открой приложение и создай задачу на 2–3 минуты вперёд с напоминанием «В момент начала». В нужное время придёт сообщение с названием дела и кнопкой открытия приложения. Обработка — каждые 15 секунд плюс время ответа Telegram; повтор после сетевого сбоя — через две минуты. Напоминания старше суток пропускаются. Серверное повторение серии работает без открытой страницы.

Компьютер и Telegram-процесс должны работать. Закрытие страницы не отключает Telegram-напоминания. Выключение компьютера, остановка процесса и потеря интернета временно отключают сервис. Технической гарантии доставки «ровно один раз» нет.

## Временный адрес и постоянный сервер

Quick Tunnel Cloudflare создаёт случайный адрес `https://…trycloudflare.com`, который меняется после перезапуска. Адрес действует, пока работает процесс туннеля. Кнопка меню обновляется при каждом запуске. Старую кнопку под старым приветствием можно заменить командой `/app`.

Quick Tunnel предназначен для разработки и тестов. Для постоянной работы перенеси проект и базу `data/telegram.sqlite3` на сервер, настрой HTTPS-прокси к порту приложения и запускай `python run_telegram.py --public-url https://твой-домен --port 8766`. При этом временный туннель не создаётся. Встроенному HTTP-серверу перед публичной эксплуатацией нужны обратный прокси, ограничение запросов, резервное копирование и контроль постоянной работы.

## Авторизация

Доступ к данным разрешён только после проверки `Telegram.WebApp.initData` на сервере: HMAC, срок `auth_date`, уникальность параметров. `initDataUnsafe` не используется для авторизации. Внешняя сессия имеет cookie `Secure; SameSite=None; HttpOnly`. Без initData создание публичной сессии запрещено. Пользователь определяется из серверной сессии. Чужой `user_id` в теле запроса не даёт доступ к чужим данным.

Файл `data/telegram-runtime.json` содержит статус процесса, имя бота, адрес и порт без токена. Не публикуй папку data или `.env`; они исключены из Git и релизного архива.

## Если не открывается

- Убедись, что Telegram-процесс продолжает работать и не сообщил об ошибке туннеля.
- Отправь `/app`, чтобы получить текущую ссылку, либо используй кнопку меню.
- Не открывай временный сайт как обычную веб-страницу для входа: запускай из Telegram.
- Если появилась ошибка подписи после долгого открытого сеанса, закрой Mini App и открой заново.
- Если Telegram сообщает о конфликте получателя, останови другой процесс этого бота. Чужой webhook нужно менять отдельно осознанно.
