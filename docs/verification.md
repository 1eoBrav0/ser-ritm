## v2.6 · Подготовка к хостингу · 19 октября 2026

Подготовлен WSGI-запуск для PythonAnywhere, webhook Telegram с отдельным секретом, защищённая проверка напоминаний для cron-job.org и резервное копирование SQLite. 50 тестов Python прошли, включая WSGI validator, изоляцию, повторы webhook, ограничения cron и согласованную копию базы. 9 проверок fullscreen и 16 утверждений Planner прошли; синтаксис JS проверен. При проверке резервной копии на Windows выявлено незакрытое соединение SQLite; исправлено через contextlib.closing, повторный полный запуск успешен.

Облачная публикация ещё не выполнена: пользователь создаёт аккаунты хостинга и входит в GitHub. Существующий Telegram-процесс не остановлен, webhook и меню реального бота не менялись. Проверка на настоящем сервере, перенос базы и реальное уведомление остаются обязательными после доступа к аккаунтам.
